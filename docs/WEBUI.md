# 配置 WebUI

AstrBot 插件详情页现在提供 `settings` 视图，用于配置：

- 启用状态、人格来源、私聊会话和机器人白名单。
- 角色称呼、身份、性格、边界。
- 单条专属关系及绑定目标。
- 语气、长度、动作、表情和套话控制。
- 对话示例。

打开 AstrBot WebUI → 插件 → `astrbot_plugin_digital_life_personality` → 插件详情 → `settings`。页面使用 AstrBot Dashboard 的登录态，不另开端口。

页面保存会执行严格配置校验：角色必填项、会话/机器人关系绑定、枚举值和 12,000 字符预算不通过时不会改变当前运行配置。保存成功后，新模型请求立即使用新配置；页面显示的“有效/无效”只代表配置校验，不代表模型一定遵循语气。

如果页面没有出现：

1. 运行 `Sync-Plugin.cmd` 同步 `views/settings/`。
2. 在 AstrBot 插件页重载插件。
3. 刷新插件详情页；新增视图目录需要重载后才会被宿主发现。

该页面不会显示聊天记录、模型密钥或 NapCat token。

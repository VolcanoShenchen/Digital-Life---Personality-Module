# 配置 WebUI

在AstrBot插件详情中打开 `settings` 视图。Vue页面复用Dashboard登录和桥接API，不另开服务或端口。

## 两级模块入口（0.4.1）

顶部是可点击的一级模块导航，先选择模块，再查看该模块内部内容。

| 一级入口 | 内容 |
| --- | --- |
| 人格模块 | 稳定的角色身份、经历、性格、行为习惯与表达规则；内部有二级分组 |
| 日程模块 | 生成模式、作息、工作日、固定模板和今日安排编辑器 |
| 当前状态 | 人工临时活动、位置、情绪、精力及作用域和有效期 |
| 通用设置 | 插件总开关、允许私聊UMO和机器人QQ号 |

日程和当前状态不会出现在人格模块的二级列表中。模块增长时新增一级入口，避免把所有子页混成一列。未来情绪、记忆模块尚未实现，不显示不可操作的占位入口。

人格模块的二级目录：

| 分组 | 内容 |
| --- | --- |
| 身份控制 | 人格来源、叠加/角色主控模式、助手身份抑制、技术信息披露 |
| 基础资料 | 姓名、昵称、性别认同、年龄、职业、教育和常住地 |
| 经历与世界 | 身份、家庭、成长、历史、长期背景、知识范围和世界设定 |
| 性格核心 | 性格、优缺点、价值观、恐惧、动机和自我评价 |
| 情境行为 | 不同情绪/事件发生时怎样回应；这是条件规则，不证明当前情绪 |
| 专属关系 | 关系身份、阶段、称呼、共同经历、信任和相处规则 |
| 说话方式 | 词汇、句式、标点、幽默和措辞 |
| 回复策略 | 长度、追问、建议、未知处理及套话控制 |
| 动作与场景 | 动作描写、环境和感官偏好 |
| 边界保护 | 隐私、现实行为、记忆、工具与角色边界 |
| 对话示例 | 风格示范，不是实际记忆 |

## 切换与保存

- 模块按钮切换整个工作区，二级目录只切换人格内部内容。
- 切换模块会保留当前配置草稿及未保存的今日安排；返回人格模块恢复本次页面最后选择的子页。
- 关闭或刷新页面会丢弃未保存草稿；本版不在浏览器持久化草稿。
- 底部“保存全部配置”统一保存人格、日程设置、当前状态及通用设置，校验失败保留原运行配置。
- 今日安排是单独数据，仍需在日程模块点击“保存今日日程”；保存配置不会擅自提交未保存的日程行。
- 配置读取失败时禁止保存，防止用默认空表覆盖配置。
- 保存成功后新请求立即生效，插件API返回真实持久化结果。

默认选择人格模块。各模块标题和面包屑表明当前位置，窄屏导航换行，一级按钮可以使用Tab聚焦、Enter激活。

## 身份控制与通用设置

身份控制移到“人格模块 → 身份控制”，不再出现在所有页面顶部。推荐使用“插件管理完整人格 + 角色主控模式”。如选择沿用AstrBot人格，请使用叠加模式。

全局生效范围位于“通用设置”。插件运行仍要求完整UMO和机器人ID同时匹配，不会根据昵称推断，也不会修改AstrBot原生人格。

## 数据兼容

此次仅调整页面结构，配置键保持不变。`profile`、`personality`、`schedule`、`dynamic_state`及允许列表沿用原解析和保存机制。现有角色资料不会自动复制或删除。

旧 `character.*` / `expression.*` 的内存兼容迁移仍保留；旧 `background.current_situation` 保留待人工迁移但不注入。

## 构建与访问

源码在 `frontend/`，执行 `pnpm run build` 输出到 `views/settings/`，发行包只包含编译后的相对路径哈希资源。同步宿主插件目录后刷新插件视图；运行时版本变化需重载插件。

页面不显示模型密钥或OneBot token，配置只通过经过认证的Dashboard请求返回。真实浏览器验证采用官方iframe/SDK和本地API，详细范围见 [验证记录](VALIDATION.md)。

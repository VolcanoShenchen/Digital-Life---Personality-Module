# 项目状态与后续计划

当前交付目标：0.4.0今日日程测试版。基于全新插件架构，以AstrBot 4.29.4、Python 3.12+、内置Agent及QQ私聊为开发基线。

## 模块状态

| 模块 | 当前实现 | 仍需验证或后续扩展 |
| --- | --- | --- |
| 人格 | 结构化身份、经历、性格、行为规则、表达、边界；角色主控 | 实际模型长期一致性 |
| 关系 | 单条专属关系，UMO+机器人绑定 | 多关系路由、关系成长 |
| 当前状态 | 人工活动、位置、情绪、精力、来源与有效期 | 自动情绪识别和状态更新 |
| 日程 | 可选开关、角色作息生成、固定安排、今日存储、当前段、跨日检查、人工编辑 | 模型自由规划、节假日、跨夜工作班次、多角色日历 |
| WebUI | Vue配置、日程编辑及真实浏览器保存回读验证 | 按用户反馈继续改进 |
| 记忆 | 使用AstrBot聊天历史，无独立记忆库 | 有来源的长期记忆 |
| 投递 | 使用AstrBot宿主发送 | 独立连续气泡、取消余段及失败语义 |

## 当前测试与交付

- 116项自动化测试、Ruff检查、Vue生产构建。
- 真实本地宿主重载，真实Edge表单操作与API持久化回读。
- 真实AstrBot请求对象及历史序列化器验证临时内容不保存。
- 交付完整ZIP及SHA-256；运行数据、凭据、依赖与本地浏览器profile均不入包。
- 代码在 `feature/schedule-v0.4` 提交，默认main未自动合并；此次不推送远端、不改云端配置。

## 日程使用与下一步

开启“今日日程”并保存，默认按角色和作息创建今日安排；用户可查看当前卡片，人工编辑并保存，再开始QQ试聊。生成是角色生活模拟，不是真实动作执行。

接下来重点观察时段切换、人工状态优先和次日安排。分段消息作为独立需求继续推进，避免日程模块直接接管普通发送链路。
